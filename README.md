# Weather App

- The Weather App is a simple web application that allows users to check the current weather of any city. By entering a city name, the app fetches real-time weather data using the OpenWeatherMap API and displays key weather details

# What did I learn?

- Using APIs: Learned how to fetch data from a third-party API (OpenWeatherMap) using fetch and handle JSON responses
- Event Handling in JavaScript: Gained experience with adding click event listeners to trigger specific functions
- DOM Manipulation: Improved skills in dynamically updating HTML content based on user input and API data
- Responsive Design Practices: Understood the importance of building apps that work across different devices and screen sizes
- Debugging Async Code: Learned how to troubleshoot and debug asynchronous JavaScript code effectively
